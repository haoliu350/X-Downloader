Project Requirements Document: Twitter Downloader

The following table outlines the details functional requirements for the Twitter Downloader project.
| Requirement ID | Description                   | User Story                                                                                      | Expected Behaviour/Outcome                                                                                               |
|----------------|-------------------------------|-------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------|
| 1              | Show existing Twitter profile | As a user, I want see all the Twitter user profile I added before in a list                     | The system should provide a clear way to show all the Twitter user profile existing in the database                      |
| 2              | Add a new Twitter profile     | As a user, I want to add a new Twitter user profile to the list                                 | The system should allow the user to input the Twitter profile link and add it to the list                                |
| 3              | Delete a Twitter profile      | As a user, I want to delete a Twitter user profile from the list                                | The system should allow the user to select a Twitter profile from the list and remove it                                 |
| 4              | Load Cookie from browser      | As a user, I want to fetch cookie from Chrome or Firefox, which already has logged into Twitter | The system should give user dialog to select which browser to use, and then try to fetch all needed authentication related tokens from browser ans store it         |
| 5              | Add login cookie manully      | As a user, I want to provide logged in cookie manually, if auto load from browser doesn't work  | The system should allow the user to input their logged in cookie and store to database                                   |
| 6              | Download tweets media         | As a user, I want to download all the images and videos from a Twitter user profile             | The system should pop up ask user to select a file system location for the first time, and download new images and videos based on the profile last downloaded timestamp |
